# v2.2.3-beta.2

Second prerelease of the minimal OpenWrt integration planned for v2.2.3.

- Keeps opkg-native `~beta` ordering inside IPK metadata.
- Normalizes the public beta IPK filename before checksums and GitHub upload, so
  `SHA256SUMS` matches the downloadable release asset exactly.
- Otherwise retains the beta.1 raw-binary plus LuCI APK/IPK distribution model.
