# v2.2.3-beta.1

First prerelease of the minimal OpenWrt integration planned for v2.2.3.

- Reuses the existing regular or UPX static musl release binary.
- Packages only the architecture-independent LuCI/procd/UCI integration.
- Publishes APK (`noarch`) for OpenWrt 25.12+ and IPK (`all`) for 24.10.
- Preserves one-line remote installation with stable/beta and regular/UPX selection.
- Migrates the superseded test-only core package model to the raw binary layout.
