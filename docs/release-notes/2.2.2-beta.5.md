# v2.2.2-beta.5

Test prerelease for the simplified OpenWrt package publication and installer flow.
The Rust application is unchanged from v2.2.2.

## OpenWrt release layout

OpenWrt packages are now published as direct release assets instead of CPU-family
bundle archives. The release contains:

- one core APK and one core IPK for each real binary ISA: `aarch64`, `armv7`,
  `mips`, `mipsel` and `x86_64`;
- one architecture-independent LuCI APK and IPK;
- one shared `SHA256SUMS` covering all twelve packages.

Device-specific OpenWrt optimization labels no longer create duplicate package
payloads. The installer maps a compatible `DISTRIB_ARCH` to its real CPU ISA and
downloads only the selected core package, LuCI package and checksum manifest.

For legacy opkg systems, the installer reads the IPK architecture before using
`--force-architecture` and rejects a package whose ISA does not match the device.
ARMv6 and MIPS32r1 labels are intentionally not mapped to the ARMv7/MIPS32r2
release binaries.

## Install this prerelease

```sh
wget -qO- https://raw.githubusercontent.com/Lyedok/tg-ws-proxy-rs/v2.2.2-beta.5/install.sh | \
  TG_WS_PROXY_REPOSITORY=Lyedok/tg-ws-proxy-rs sh -s -- --channel beta
```
